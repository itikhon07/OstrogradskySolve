# OstrogradskySolve

Образовательное веб-приложение для тренировки навыков решения задач по математике и физике.

## 📖 Описание

**OstrogradskySolve** — это интерактивная платформа, названная в честь выдающегося российского математика и механика Михаила Васильевича Остроградского (1801–1862). Приложение помогает учащимся развивать навыки решения задач в игровой форме.

### Основные возможности

- ✅ **Авторизация и регистрация** — создание учётной записи и вход в систему
- ✅ **Математика и физика** — два предмета с набором задач
- ✅ **Игровой процесс** — решение задач с мгновенной проверкой ответа
- ✅ **Система баллов** — 10 баллов за каждое правильное решение
- ✅ **Доска для заметок** — встроенный инструмент для рисования и вычислений
- ✅ **Профиль пользователя** — отслеживание статистики (решено задач, точность, баллы)
- ✅ **Версия для слабовидящих** — специальный режим с высоким контрастом
- ✅ **PWA-поддержка** — возможность установки как нативного приложения

## 🚀 Быстрый старт

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd OstrogradskySolve
```

2. Откройте `auth.html` в браузере или используйте локальный сервер:
```bash
# Например, с помощью Python
python -m http.server 8000
```

3. Перейдите по адресу `http://localhost:8000/auth.html`

### Первое использование

1. Зарегистрируйтесь, введя email и пароль (минимум 4 символа)
2. Войдите в систему
3. Выберите предмет (математика или физика)
4. Решайте задачи и зарабатывайте баллы!

## 🎨 Темы оформления

Приложение поддерживает несколько тем:

- **Стандартная тема** — светлый фон, тёмный текст
- **Тема математики** — оранжевые акценты
- **Тема физики** — фиолетовые акценты
- **Версия для слабовидящих** — высокий контраст (чёрный фон, белый текст, жёлтые акценты)

## ♿ Доступность
